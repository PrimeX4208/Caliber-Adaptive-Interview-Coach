# Mock Interview Application

Customizable application for practicing and prepping for interviews.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18+) or [Bun](https://bun.sh/)
- A Gemini API key

## Getting Started

**Clone the repository:**
   ```bash
   git clone [https://github.com/PrimeX4208/Mock-Interview-Application.git](https://github.com/PrimeX4208/Mock-Interview-Application.git)
   cd Mock-Interview-Application
   ```
**Install Dependencies:**
   ```bash
   bun install
   ```
**Start The Application:**
   ```bash
   bun run dev
   ```
